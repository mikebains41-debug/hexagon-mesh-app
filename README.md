# Hexagon Mesh app

Downloads for the Hexagon Mesh Android app, built by Manmohan Bains. While your phone charges, it processes small AI jobs for businesses, and verified work is credited to you.

## Scan to install

Point your phone's camera at this code, tap the link, then tap **Install**:

![Scan to install the Hexagon Mesh app](install-qr.png)

Or open this link on the phone (Android 9 or newer, 64-bit):
https://github.com/mikebains41-debug/hexagon-mesh-app/releases/download/latest/hexagon-mesh.apk

After the first install, updates arrive inside the app.
