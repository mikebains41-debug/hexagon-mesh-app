How your job gets done

  1. Your texts are split into small tickets of 32.
  2. Each ticket runs on two phones owned by different people, only while they're charging, cool, and on Wi-Fi.
  3. When both phones return the same answer, it's accepted. Anything that doesn't match runs again on other phones.
  4. You get every embedding back in your original order.

On a Galaxy S25 Ultra, the phone's AI chip turns about 45,700 tokens a second into embeddings, matching a full-precision computer to 0.9992.

Already using OpenAI's embeddings API?

Point your client at Hexagon Mesh and change the model name. You get the address with your key.

from openai import OpenAI

client = OpenAI(base_url="YOUR_HEXAGON_ADDRESS/v1", api_key="YOUR_KEY")
result = client.embeddings.create(
    model="all-MiniLM-L6-v2",
    input=["first document", "second document"],
)

Big batch? Send up to 100,000 texts per job to /v1/jobs, or use the file tool: a text, CSV, or JSON lines file in, an embeddings file out.
